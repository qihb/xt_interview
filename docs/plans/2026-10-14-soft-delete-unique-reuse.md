# 软删除数据唯一性优化 · 落地计划

**目标**：允许已软删除账号重新使用原用户名，同时保证未删除账号之间仍然唯一，避免新增接口因数据库唯一索引冲突返回 500。
**技术栈 / 约束**：Spring Boot 4.0.6、Java 26、Spring Data JPA、MySQL 8.0、Flyway；保留软删除模型和统一错误响应格式。
**涉及文件**：新增 Flyway 迁移、账号/部门实体、账号服务测试、Controller 异常测试。
**关键决策**：采用“仅未删除记录唯一”的方案。通过 MySQL 生成列和唯一索引实现：`deleted=0` 时生成有效值，`deleted=1` 时生成 `NULL`；账号用户名和部门编码统一处理。
**执行约定**：本计划已按用户确认的方案完成落地，阶段状态与实际实现保持同步。
