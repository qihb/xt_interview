# 接口参数校验与友好错误提示 · 落地计划

**目标**：为现有后端接口补齐参数校验和统一异常响应，让调用方能明确知道哪个字段、哪条业务规则失败。
**技术栈 / 约束**：Spring Boot 4.0.6、Java 26、Spring Data JPA、Jakarta Validation、Flyway；保持现有接口路径和字段兼容。
**涉及文件**：`dto/*DTO.java`、`controller/*Controller.java`、新增全局异常处理与业务异常类、账号/部门 Service、Controller/Service 测试。
**关键决策**：错误响应统一包含 `timestamp`、`status`、`error`、`message`、`details`；字段校验错误按字段返回，业务冲突返回 409，非法路径/查询参数返回 400，未预期异常保留通用提示但记录服务端日志。
**执行约定**：本文件仅为计划；由用户指定阶段后再执行，每完成一步勾选并记录验证结果。
